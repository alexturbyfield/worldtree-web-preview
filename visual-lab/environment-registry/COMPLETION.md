# Representative geographic pilot: completed trial coverage

The pilot now contains **42 audited locations: three in each of the 14 existing RESOLVE biome families**. All are explicit experimental previews. This completes representative trial coverage, not global geographic coverage, ecological verification, artistic approval or deployment.

Open `/explore` and expand **Approved reference scenes → Geographic pilot · experimental**. The fifteen accepted reference recipes remain separately selectable and protected. Ordinary map routing still uses its existing conservative behavior.

## Final eight families

| Family | Three trial regions | Reused representation and limitations |
| --- | --- | --- |
| Tropical moist forest | Amazon; Congolian coastal forest; Borneo | Actual regional input candidates, existing geometry, shared forest-floor/depth components. Tidal-root taxa are excluded. Unsupported tree shapes remain labelled approximations; no Amazon species list is exported to other continents. |
| Tropical conifer forest | Guatemala; Cuba; Himalayan subtropical pine region | Explicitly unnamed conifer growth forms where the resolved catalogue lacks eligible pines. No hardcoded Guatemalan names are inserted. Needle anatomy and local species require further evidence. |
| Temperate conifer forest | Puget; Alps; coastal British Columbia | Existing genus-conditioned conifer adapter and supported regional candidates. It is a transfer study, not a replacement for the accepted Puget artwork. |
| Savanna | Tanzania; Cerrado; Arnhem Land | Existing grassland materials, dimensional vegetation and rolling continuation, with no unsupported woody species. Open patches do not establish that a whole savanna is treeless; regional woody communities remain a gap. |
| Flooded grassland | Everglades; Pantanal; Inner Niger Delta | Retained irregular wetland field model and environment-derived water optics. Grass/sedge forms are unnamed; local hydroperiod and wooded patches are not measured. |
| Montane grassland | Cordillera Blanca; Ethiopian moorland; Altai | Existing tussock/cushion/rock components. All pilot views withhold the named Andean tree/rosette roles; the accepted Andean reference is unchanged. The Cordillera Blanca matte is allowed only at its original regional trial. |
| Mediterranean woodland | Hérault; southwest Iberia; Italy | Resolved cork/holm oak candidates and retained ground/grass treatment. The Hérault matte is withheld outside its geographic envelope. |
| Desert / xeric shrubland | Mojave; Atacama; Namib | Retained weathered geology, sparse cover and open-horizon terrain. The Mojave distance painting is withheld in other regions. Rockland is an artistic study, not a surveyed substrate claim. |

[Local source audit](../../artifacts/geographic-completion/audit.json) records coordinates, actual source polygons, botanical countries, candidate names and source links. Native-country evidence does not establish selected-point occurrence, abundance, habitat, phenology or botanical dimensions. The tropical-conifer gap includes both incomplete catalogue coverage and conservative eligibility filtering; an empty eligible pool is not evidence that native pines are absent.

## Readiness and next work

The new routes run and retain the protected artwork. Several transfers still expose finite forest stands, generic tree architecture, repetitive ground fields, limited woody-community data or weak distance after a foreign matte is removed. These are unresolved artistic and data defects, not approved global rules. Device performance, actual terrain/hydrology and regional nonwoody catalogues remain separate gaps.

The reusable result is a guarded route from source category and regional candidate data into existing adapters, with unsupported identities and assets kept explicit. The next phase should address the recorded gaps and validate a carefully bounded automatic resolver. Do not activate worldwide routing simply because all family IDs now have representative trials.
