# Fast prototype
1. Identify one visible outcome and the smallest existing code path that produces it.
2. Edit at most 3 files unless impossible; preserve the existing fallback.
3. Avoid new libraries, large refactors, broad research, extensive tests, and deployment.
4. Run a targeted check only when useful. Never report checks that did not run.
5. Respond with a short change summary and a direct way to preview it.
6. Stop when the requested experiment is visible; do not autonomously start follow-up features.
