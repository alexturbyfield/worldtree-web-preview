# Visual review
- Compare overall silhouette, canopy cohesion, leaf-edge breakup, color hierarchy, exposed branches, and species identity.
- Identify at most 3 visible discrepancies, ranked by impact.
- Recommend one specific next experiment, not a complete rewrite.
- Do not assert technical causes that cannot be established from a screenshot; label them hypotheses.
- Do not code unless explicitly requested.
