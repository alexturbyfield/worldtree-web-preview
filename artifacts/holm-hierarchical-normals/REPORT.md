Link is also added to the Lab review page. Three sliders normalize their nonnegative weights by the sum; defaults are crown0.45, cluster0.40, leaf0.15. Buttons show exact original cards, current hull and weighted blend. This is a local render-backed viewer using one persistent existing-renderer browser, not a new renderer or scene generator. Inputs update normals on one diagnostic clone only.

The crown field is a genuine3D ellipsoid fitted to the original cluster bounds in all three tree-local axes. Each local field uses its original cluster center and radii; each card uses its exact original normal from studioGeometry. Vectors are normalized, transformed consistently to world space, blended and normalized again. A positive sum is required; exact cancellation falls back to the crown normal. This is a volumetric hull approximation, not a convex hull or camera depth map. Current-hull comparison uses the exact existing continuous normal attribute, not the new fitted field.

Only normal attributes change. Captures verify identical position/UV/index signatures, silhouette masks, camera, exposure, submitted triangles and draw calls.
